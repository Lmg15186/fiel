# FIEL video script — target 1:45

Record in English, 1080p, with the browser zoomed so receipts are readable.
Use only the FIEL interface and voice-over; no third-party football footage,
club marks or music.

## 0:00–0:15 — Problem

**Screen:** Match Room title, then live metrics.

**Voice:** “Live football creates thousands of events, but a production team
needs one trustworthy story now. Generative AI is fast, yet a confident wrong
number cannot go on air. FIEL turns synthetic match events into explainable
intelligence where every sentence comes with a receipt.”

## 0:15–0:40 — Predictive story

**Screen:** `m-003-T4-T3`; move across minutes 59 to 79 and point to pressure,
xG and win probability.

**Voice:** “Our deterministic engine tracks pressure, shot quality and a
transparent Monte Carlo win outlook. Match Memory adds what is usual for each
fictional team, so FIEL can explain not only what happened, but what changed.”

## 0:40–1:12 — Agents and evidence

**Screen:** Agent Desk; point to framework banner, stages, baseline and receipt.

**Voice:** “Microsoft Agent Framework orchestrates three specialised roles.
The Foundry Explainer proposes a claim with metric, window and event IDs. Python
independently recomputes it before the Producer can rank it. The Personalizer
adapts approved facts for analysts or fans in English or Portuguese, then the
receipt is verified again. If wording drifts, FIEL falls back safely.”

## 1:12–1:32 — Failure recovery

**Screen:** Verification Lab, rejected causal sentence and accepted correction.

**Voice:** “Here, an unsupported claim that a substitution won the game is
blocked. The system returns a precise reason, rewrites it as measurable
evidence, and only then marks it on air.”

## 1:32–1:48 — Evidence and close

**Screen:** Data & Ground Truth, then repo/demo URL.

**Voice:** “Across thirty reproducible matches, FIEL detected all forty-nine
planted signals, rejected all forty-nine unsafe causal claims, and accepted all
forty-nine safe corrections. FIEL: real-time stories, historical context, and
evidence a broadcaster can inspect.”
